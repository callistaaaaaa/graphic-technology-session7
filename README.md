## 📸 Overview

Website portfolio personal **Calandra Alencia Haryani** — dibangun dengan HTML, CSS, dan JavaScript murni menggunakan estetika modern dengan efek visual yang imersif.

---

## ✨ Fitur Utama

| Fitur | Deskripsi |
|---|---|
| 🎞️ **Matrix Canvas Effect** | Animasi latar belakang interaktif pada hero section |
| 🪪 **Draggable Lanyard ID** | Kartu ID yang bisa digeser menggunakan drag & drop |
| 💬 **Typing Text Animation** | Efek mengetik otomatis pada teks sambutan |
| 🖼️ **Project Slider** | Navigasi kartu proyek dengan slider yang smooth |
| ✉️ **Envelope CTA Section** | Bagian contact berbentuk amplop yang interaktif |
| 💬 **Floating WhatsApp Button** | Tombol kontak WhatsApp yang selalu terlihat |
| 📱 **Responsive Design** | Tampilan optimal di semua ukuran layar |

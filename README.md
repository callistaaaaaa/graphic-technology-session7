## 📸 Overview

Website portfolio personal **Calandra Alencia Haryani** — dibangun dengan HTML, CSS, dan JavaScript murni menggunakan estetika modern dengan efek visual yang imersif: matrix canvas animation, claymorphism cards, draggable lanyard ID card, dan typing text animation.

---

## ✨ Fitur Utama

<div align="center">

| &nbsp;&nbsp;Fitur&nbsp;&nbsp; | Deskripsi |
|:---:|---|
| 🎞️ **Matrix Canvas** | Animasi latar belakang interaktif pada hero section |
| 🪪 **Draggable Lanyard** | ID card yang bisa digeser dengan drag & drop |
| 💬 **Typing Animation** | Efek mengetik otomatis pada teks sambutan |
| 🖼️ **Project Slider** | Navigasi kartu proyek dengan scrolling smooth |
| ✉️ **Envelope CTA** | Contact section berbentuk amplop interaktif |
| 💬 **Floating WhatsApp** | Tombol WA yang selalu tampil di semua halaman |
| 📱 **Responsive Design** | Tampilan optimal di semua ukuran layar |

</div>

## 🗂️ Struktur Proyek

```
📁 workshop/
│
├── 📄 index.html              # Halaman utama portfolio
│
└── 📁 asset/
    ├── 📁 css/
    │   ├── style.css          # Stylesheet utama (neumorphism + claymorphism)
    │   └── style2.css         # Stylesheet tambahan
    ├── 📁 js/
    │   └── script.js          # Logic: canvas, drag, slider, typing
    └── 📁 image/
        ├── favicon.png        # Ikon tab browser
        ├── char-center.png    # Karakter ilustrasi hero
        └── lanyard.png        # Gambar ID card lanyard
```
